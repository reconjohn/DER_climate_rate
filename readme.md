# Household energy use and costs in residential energy transition shaped by climate and electricity rates

## Project Overview

This repository contains the full analysis code for the research project investigating the impacts of Distributed Energy Resource (DER) adoption on residential energy consumption and household expenditures in the United States. The study quantifies how the adoption of technologies like rooftop solar PV, electric vehicles (EVs), and heat pumps alters household energy usage and utility bills. The findings aim to inform policymakers, utilities, and consumers about the economic and regional-level consequences of the ongoing energy transition.

---

## Repository Structure

The workflow is organized into four main scripts, separating setup, data processing, analysis, and output generation.

* `o_function.R`:
    * **Purpose**: Setup Script.
    * **Description**: This script loads all necessary R libraries and defines any custom helper functions that are used across the project. It ensures a consistent and reproducible R environment for the analysis.

* `o_data.R`:
    * **Purpose**: Data Processing and Loading.
    * **Description**: This is the core data preparation script. It ingests raw data from various sources, performs all necessary cleaning, merging, and feature engineering, and then loads the final, analysis-ready datasets into the global environment. This script may be computationally intensive.

* `o_code.R`:
    * **Purpose**: Analysis and Plot Generation.
    * **Description**: This script contains the main analytical and statistical modeling code. It takes the clean data loaded by `o_data.R`, runs regressions or other models, and generates the plot objects (e.g., `ggplot` objects) for visualization. The plot objects are stored in memory but are not saved to disk by this script.

* `plot.R`:
    * **Purpose**: Save Plots to Disk.
    * **Description**: This script takes the plot objects generated by `o_code.R` and saves them as files (e.g., `.png`, `.pdf`) in an output directory. This separation allows for centralized control over the appearance and formatting of all saved figures (e.g., dimensions, resolution, file type).

---

## Workflow Pipeline

The analysis follows a linear sequence. Each script prepares the environment or produces artifacts for the next script in the chain.

1.  **Setup**: Run `o_function.R` to load libraries and functions.
2.  **Data Processing**: Run `o_data.R` to clean raw data and create the final dataframes for analysis.
3.  **Analysis**: Run `o_code.R` to perform the analysis and generate plot objects.
4.  **Output**: Run `plot.R` to save the generated plots to the `/output/plots/` directory.
